# 发布前 QA

输出前检查：

- [ ] 内容是否比设计更先被看见？
- [ ] 是否过度设计或模板感过强？
- [ ] 标题层级是否过多？
- [ ] 是否滥用卡片/色块？
- [ ] 色彩是否超过必要范围？
- [ ] 真实图片是否承担了叙事作用？
- [ ] 阅读节奏是否有留白和呼吸？
- [ ] 品牌色/Logo 是否自然，而不是到处贴？
- [ ] 是否擅自改写作者观点和语气？
- [ ] 是否复制了参考案例的 Logo、水印或专属资产？
- [ ] 是否暴露儿童姓名、班级等不必要身份信息？
- [ ] HTML 是否依赖 flex/grid/absolute 等高风险关键布局？
- [ ] 核心字号、行高、对齐、图片尺寸是否内联？
- [ ] 文末、引用、双图等关键模块复制到微信后仍能成立？

出现明显问题时先修正，再交付。
