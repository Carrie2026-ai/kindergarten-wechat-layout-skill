# Xiumi Tuning Guide｜秀米微调指导

## 定位

秀米 / 135 / 公众号后台不是“重新排版工具”，而是最后的视觉精修层。

默认目标：

> AI 完成约 90% 排版，人工只处理最后约 10% 的素材与局部细节。

## 与 Visual Archetype 的关系

Visual Archetype 决定“应该往什么方向长”。

秀米负责把 HTML 不擅长的部分补上，例如：
- 真实小插画；
- 园所 IP；
- Logo；
- 纸张纹理；
- 格子素材；
- 透明 PNG；
- 图片裁切；
- 最后局部留白。

不要把秀米当成第二次重新设计。

## 最终输出必须告诉用户

先明确：

**当前版本已经可以直接发布。下面的修改都是可选增强，不需要从头重排。**

然后识别 3–6 个最值得微调的位置。

## 每个位置都要回答 4 件事

1. 当前是什么；
2. 可以改成什么；
3. 去秀米搜索什么关键词 / 用什么园所自有素材；
4. 是否必要。

推荐表格结构：

| 位置 | 当前效果 | 秀米可怎么调 | 推荐素材 / 搜索词 | 必要性 |
|---|---|---|---|---|

## 按 Visual Archetype 给出不同微调重点

### 园所官方型
优先微调：Logo、栏目固定图、活动主图、品牌色一致性。

### 秀米轻童趣型
优先微调：小书本、小花、叶片、阅读 IP、浅纹理。

### 温暖活动型
优先微调：大照片裁切、双图关系、暖色小装饰。

### 课程故事杂志型
优先微调：过程主图、证据截图、儿童作品、图片顺序。

### 成果展示型
优先微调：关键证据图、阶段结论图、成果照片、必要 Logo。

### 极简园刊型
通常只微调：图片质量、局部留白、栏目固定识别。不要主动加装饰。

## 常见可调位置

### 1. 标题附近的小装饰
适合：小叶片、小花、小书本、栏目 IP。

建议：只放 1 组，不要左右都堆满。

搜索词可用：
- 手绘叶子
- 小花
- 阅读
- 书本
- 自然
- 儿童手绘

### 2. 主要插画位
适合：亲子共读、班级 IP、活动主视觉。

优先：园所自己的视觉资产 > 通用素材。

### 3. 活动照片
可以在秀米里：
- 替换占位图；
- 调整裁切；
- 做简单双图；
- 检查上下留白。

不要：复杂拼贴、重滤镜、花哨相框。

### 4. 背景纹理
如果用户特别想要：
- 格子纸；
- 水彩纸；
- 淡纸纹；
- 手绘边角。

不要再写 CSS。

在秀米中使用真实图片素材，或把纹理做成一张合法素材图。

纹理只做陪衬，不能影响文字可读性。

### 5. 园所 Logo / 栏目固定图
只有真正有品牌识别需求时再加。

不要求每一屏都出现 Logo。

### 6. 局部留白
如果某两个区块太挤，只改上下间距。

不要因此重新改字号体系。

## 不建议再动

默认提醒用户：
- 不随意更换整篇主色；
- 不重新建立标题字号层级；
- 不给每段加卡片；
- 不大量增加圆角边框；
- 不堆贴纸；
- 不为了“童趣”增加高饱和色；
- 不为了“高级”增加阴影、纹理、英文和复杂装饰；
- 不破坏已经成立的留白。

## 最后一句

秀米真正擅长的是：

**素材管理 + 视觉组合 + 人工微调 + 与公众号衔接。**

Skill 负责结构、层级、Visual Archetype 和大部分视觉判断；秀米只补 HTML 不擅长的那一小部分。
