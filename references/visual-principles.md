# Visual Principles｜公开版视觉原则

## 1. 设计服务阅读

优先级：

**内容 > 阅读 > 图片 > 品牌 > 装饰**

不要为了“看起来排过版”而制造过多模块。

## 2. 先看内容类型，再决定设计强度

- 家园共育：亲切、清楚、低负担；
- 亲子 / 节庆：允许轻童趣，但不堆贴纸；
- 课程故事 / 儿童观察：真实照片与过程证据优先；
- 教研 / 成果：结构清楚、强调克制。

## 3. 强调阶梯

优先从轻到重：
1. 留白；
2. 单独成段；
3. 字重；
4. 品牌色；
5. 细线 / 虚线；
6. 极浅背景；
7. 卡片。

前一级能解决，就不要升级。

## 4. 童趣不等于幼稚

允许：
- 奶油、米白、低饱和绿、浅杏；
- 少量圆角；
- 虚线；
- 小圆点；
- 一处真实插画或园所 IP。

避免：
- 高饱和彩虹；
- 每段一个卡片；
- 每章一种颜色；
- 大量卡通贴纸；
- 装饰比内容更抢眼。

## 5. 图片必须有任务

优先级：

**真实活动照 > 儿童作品 > 记录截图 > 园所自有插画 / IP > 必要生成图 > 无意义装饰图**

复杂氛围（格纹、纸张纹理、叶片、小花、水彩边角）必须作为真实图片素材处理，不使用 CSS 伪造。

## 6. 背景只做一件事：建立统一气氛

整篇背景优先使用一个主背景色。

局部卡片最多使用 1–2 种辅助浅色。

不要做“每一屏一种背景”。
