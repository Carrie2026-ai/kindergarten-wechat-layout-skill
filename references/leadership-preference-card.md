# Leadership Preference Card｜园所 / 领导视觉偏好卡

## 什么时候生成

当用户提供 2–5 张“园长 / 领导喜欢的公众号截图”、过去园所文章或明确的审美反馈时，建议提取一张视觉偏好卡。

这张卡不是评价领导审美，而是减少反复修改。

## 分析维度

1. **整体倾向**：正式 / 温暖 / 童趣 / 专业 / 杂志感 / 极简。
2. **标题**：居中 / 左对齐；大标题 / 小标题；标签 / 细线 / 无容器。
3. **颜色**：主色、辅助色、点缀色；是否喜欢整篇底色。
4. **图片**：单张大图 / 双图 / 多图；是否喜欢圆角；照片是否主导。
5. **装饰**：花、叶、书本、IP、虚线、小圆点的接受度。
6. **背景**：纯白 / 米白 / 奶油 / 纹理图片。
7. **信息密度**：低 / 中 / 中高。
8. **卡片密度**：低 / 中 / 高。
9. **品牌露出**：Logo、园名、栏目名出现位置。
10. **明确避免**：领导曾否定或用户明确不喜欢的视觉特征。

## 使用原则

以后排版优先执行：

`文章内容判断 × 园所视觉偏好卡 × 当前品牌资料 × 当前参考图 × 微信兼容规则`

偏好卡不能推翻内容逻辑。例如领导喜欢卡片，也不意味着每段都必须变成卡片。

如果新参考图与旧偏好卡明显冲突，要指出冲突并以当前用户要求为准，不要假装偏好始终一致。

## 隐私

偏好卡只总结视觉特征，不记录儿童身份信息，不把真实截图或第三方素材自动放入公开模板。
